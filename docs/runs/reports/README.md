# Run reports

One file per run, written by `scripts/run_card.py` as `run_report_<card>[_seed<k>].md` and
committed here by the person who ran it (it is also in `results_to_commit/docs/runs/reports/`
of the run's output). A card split by seed has one report per seed, so two people never edit
the same file. The card's own section 6 points here.
